# Java Counter Application

A beginner-friendly Java application developed using NetBeans IDE that demonstrates the use of a while loop to perform iterative counting operations.

## Project Overview

The Java Counter Application is a simple console-based program designed to showcase loop control structures in Java. The application counts sequentially from 1 to 5 and displays each value in the console output.

This project was created to practice and reinforce the fundamentals of iterative programming and program flow control.

## Features

- Automatic counting functionality
- While loop implementation
- Sequential number generation
- Console-based output
- Simple and readable code structure
- Beginner-friendly logic

## Technical Features
